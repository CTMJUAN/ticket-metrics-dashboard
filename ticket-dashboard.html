Synced Folder (Automatic)

Point this at your local OneDrive/SharePoint-synced folder once, and it reads every .csv in it (including up to three levels of subfolders, e.g. per-agent folders) directly off disk — no uploading, no network request. Needs Chrome or Edge on desktop.

Checking for a previously connected folder…

Or Upload Manually

Add one or more ticket export CSVs by hand; they're combined with each other and with any synced-folder data into one view. Re-adding a file with the same name replaces the earlier copy.

Complaint types

Combine labels that mean the same thing so the Top complaints chart (Type view) counts them together. Differences in capitals, spacing, punctuation and plurals (e.g. “Password reset” / “password-resets”) are combined automatically, and blank complaint values are ignored.

Load data to see complaint types.

Data filters

A ticket is left out when its customer, complaint, category or agent is “test”, “testing”, “test ticket” or a numbered one like “test 2” (any capitals). Labels that only contain the word, like “Self-test fault”, are kept.
