Ticket tracker admin

Open the shared folder that holds your agents’ ticket-work-log files to see and correct every agent’s work log.

Nothing leaves this computer: the page only reads and writes files in the folder you choose. Agents’ own log files are never changed — your edits are kept in ticket-admin-corrections.json in that folder.

Totals use the filters above and your corrections. Removed and deleted tickets aren’t counted.

“Reset PIN” sets a new PIN in the agent’s account file in this folder. Their tracker (v4.10 or later) accepts it the next time they sign in.

Settings

Appearance

Shared Log Folder

One folder for the whole portal — usually the OneDrive/SharePoint-synced folder your agents’ trackers log to. The dashboard reads every .csv in it (including up to three levels of subfolders, e.g. per-agent folders); the admin views read and correct the agents’ ticket-work-log and account files in it. Choose Allow / Edit when the browser asks, so admin corrections can be saved. Read straight off disk — no uploading, no network request. Needs Chrome or Edge on desktop.

Or Upload Manually

Add one or more ticket export CSVs by hand; they're combined with each other and with any shared-folder data into one dashboard view. Re-adding a file with the same name replaces the earlier copy. (Uploads feed the dashboard only; the admin views work from the shared folder.)

Complaint types

Combine labels that mean the same thing so the Top 5 Complaints chart (Type view) counts them together. Differences in capitals, spacing, punctuation and plurals (e.g. “Password reset” / “password-resets”) are combined automatically, and blank complaint values are ignored.

Load data to see complaint types.

Data filters

A ticket is left out when its customer, complaint, category or agent is “test”, “testing”, “test ticket” or a numbered one like “test 2” (any capitals). Labels that only contain the word, like “Self-test fault”, are kept.
